# مساعدي AI — حزمة الاستضافة

هذه الحزمة مجهزة للنشر من الهاتف على خدمة استضافة تدعم Node.js.

## المتغيرات السرية
أضف في إعدادات الخدمة:
- OPENAI_API_KEY = مفتاح API الخاص بك
- MODEL = gpt-5.6-luna

لا تضع المفتاح داخل `index.html` أو `app.js` ولا ترسله في المحادثة.

## أمر التشغيل
npm start

## المنفذ
الخادم يستخدم PORT الذي توفره خدمة الاستضافة.

## بعد النشر
افتح رابط الخدمة من هاتف Android. ستظهر واجهة «مساعدي AI» وتستخدم `/api/chat` على نفس الخادم.

## ملاحظة
قد تحتاج خدمة الاستضافة إلى إعدادات خاصة بملفات Node.js أو أمر البناء. استخدم Node 20 أو أحدث.
